# Pocket Tools

A dependency-free static website for small browser utilities. The first tool builds a six-position frequency model from historical first-prize results in [`new4761/Thai_lottery_analysis`](https://github.com/new4761/Thai_lottery_analysis), then samples it with the Web Crypto API.

## Run locally

```sh
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Test

```sh
node --test
```

The repository is intended for the `new4761.github.io` GitHub Pages user site.
